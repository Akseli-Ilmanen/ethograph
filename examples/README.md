# Examples

Jupyter notebooks showing how real-world datasets were converted into the
ethograph `TrialTree` format, and how the model pipelines are run on them.
They are rendered in the documentation under
[Examples](https://ethograph.readthedocs.io/en/latest/examples/index.html).

## Add your workflow/dataset example!

If you develop a workflow with ethograph that others could reuse (a dataset
conversion, a feature-extraction recipe, a training setup), please share it.
Any of these works:

- **Open a pull request** that adds your `.ipynb` to this folder. It will be
  picked up by the docs build and shown in the gallery.
- **Email the notebook** to akseli.ilmanen@gmail.com and I will add it for you.
- **Open a GitHub issue** first if you would like to discuss it a bit before
  writing it up:
  https://github.com/Akseli-Ilmanen/ethograph/issues

See the [contributing guide](https://ethograph.readthedocs.io/en/latest/community/contributing.html)
for the development install and pull-request conventions.
